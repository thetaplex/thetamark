# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/thetaplex/thetamark/security/advisories/new). Do not open a public issue. You'll get an acknowledgement within 7 days.

Relevant areas: a Markdown file that can run script, reach Node/Electron APIs, read files it shouldn't, or navigate the app window.

## Supported versions

Only the latest release receives fixes.
